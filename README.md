# 🪖 Cold War — Official Discord Assets & Embeds

![Main Banner](https://raw.githubusercontent.com/sermalus/coldwar-images/main/assets/MAIN.png)

Welcome to the official repository for **Cold War** Discord server graphic assets and JSON embed configurations. This repository hosts permanent image links (`raw.githubusercontent.com`) and ready-to-use message templates for server information channels.

---

The project is organized into default configurations, seasonal themes, and media assets:
