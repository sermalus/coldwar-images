# 🪖 Cold War — Official Discord Assets & Embeds

![Main Banner](https://raw.githubusercontent.com/sermalus/coldwar-images/main/assets/MAIN.png)

Welcome to the official repository for **Cold War** Discord server graphic assets and JSON embed configurations. This repository hosts permanent image links and ready-to-use message templates for server information channels.

---

## 📂 Repository Structure

The files are organized into default configurations, seasonal event themes, and graphic assets:

* **Root `.json` files (outside folders):** (`rules.json`, `links.json`, `get-roles.json`, `roles-guide.json`) — **Default embeds** used for standard everyday server operation.
* **Folder `.json` files (`christmas/`, `halloween/`):** — **Seasonal/Thematic embeds** pre-configured with holiday banners.
* **`assets/` folder:** — Storage for all `.png` banners, split into base assets (`assets/`), seasonal subfolders (`assets/halloween/`, `assets/christmas/`), and tutorial screenshots (`assets/tutorial/`).

---

## 🛠️ Embed Generator Tutorial (How to Load & Update Embeds)

All server embeds are managed via **[Embed Generator (message.style)](https://message.style/app/editor)**. Follow this step-by-step guide to load a JSON file from GitHub and post or update a message in Discord.

### Step 1: Open the JSON Editor
1. Open the desired `.json` file in this GitHub repository (from the root for standard embeds, or inside `halloween/` / `christmas/` for seasonal ones) and copy its raw code.
2. Go to **[https://message.style/app/editor](https://message.style/app/editor)**.
3. Click the **`JSON`** button (pointed out by the arrow in the screenshot below) to open the JSON code window.

![Step 1 - Open JSON Editor](https://raw.githubusercontent.com/sermalus/coldwar-images/refs/heads/main/assets/tutorial/json_tutorial.png)

---

### Step 2: Paste the GitHub JSON Code & Save
1. In the pop-up window that opens, delete any existing code.
2. Paste the JSON code you copied from the GitHub file into the text field.
3. Click the **`Save`** button (pointed out by the arrow below) to load the embed into the generator.

![Step 2 - Paste JSON and Save](https://raw.githubusercontent.com/sermalus/coldwar-images/refs/heads/main/assets/tutorial/json_editor_save_tutorial.png)

---

### Step 3: Send a New Embed or Edit an Existing Message
Once your embed preview loads, look at the sending controls (marked with arrows in the screenshot below):

* **To send a new embed:** Select the target channel and click the **Send** button.
* **To edit an existing message:** You can update an already posted Discord message without deleting it (for example, when switching from Default to Halloween themes). Simply copy the **Message ID** from Discord, paste it into the dedicated **Message ID field**, and click the **Edit Message** button.

![Step 3 - Send or Edit Message](https://raw.githubusercontent.com/sermalus/coldwar-images/refs/heads/main/assets/tutorial/edit_message_send_message_tutorial.png)
